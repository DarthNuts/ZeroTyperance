# ZeroTyperance

[English version](README.md)

Независимая реализация игрового движка **Zero Tolerance** (Sega Mega Drive / Genesis, 1994) на TypeScript. Игра
работает в браузере, с картинкой консоли или в HD. Один или два игрока: кооператив по локальной сети или через
интернет.

**Бета:** HD-вид (рендерер Custom) и кооператив экспериментальные: они ещё в бета-версии и могут содержать ошибки.

**Образ ROM.** Установщик скачивает оригинальный образ ROM Zero Tolerance с сайта
[technopop.net](http://www.technopop.net/) (или с его копии на archive.org, когда сайт недоступен). Там правообладатель
Рэндел Рейсс (Randel Reiss) пишет, что "has made the original Zero Tolerance Sega Genesis ROM image royalty-free for
distribution". На той же странице сказано, что части образа ROM принадлежат Sega, которая официально так и не
разрешила его распространение. Загрузка сверяется с закреплённым SHA-256.

Сам ZeroTyperance не содержит графики, музыки, звуков, карт, текстов или таблиц данных, скопированных из игры:
страница читает всё это из образа ROM прямо в браузере и хранит результат в хранилище браузера. Кроме кода, в поставке
есть только значения правил движка (скорости, тайминги, урон и т. п., записанные числами) и тайминг кадров
демо-роликов, измеренный на консоли. Чтобы взять свою копию образа ROM, установите игру с `ZT_NO_ROM=1` и выберите
файл на странице.

Версия 0.3.0.

## Что добавлено

Игра играется так же, как на консоли. Вокруг неё ZeroTyperance добавляет:

- **Рендереры** (страница Video; **F9** переключает в любой момент):
  - *Original* — картинка консоли;
  - *Custom* (бета) — тот же 3D-вид в полном разрешении и на всю ширину окна, с текстурами самой игры и полной панорамой неба
    (нужен WebGL2);
  - *Classic smooth* — кадр консоли с плавным движением.

  Игра под ними во всех режимах одна и та же.
- **Плавное движение** (Smooth motion): вид движется с частотой вашего дисплея, а не с 12 шагами игры в секунду.
- **Раскладка HUD** Bar или Corners (**F10**). Настраиваются также размер оружия, поле зрения, разрешение и ограничение
  кадров.
- **Управление**:
  - *Original* — кнопки джойпада на клавиатуре, геймпад или сенсорное управление;
  - *Modern* — W A S D для ходьбы и шагов в сторону, мышь для поворота, стрельбы и смены предметов.

  Любую клавишу можно переназначить.
- **Кооператив** (бета) для двух игроков по локальной сети или через интернет (см. «Кооператив» ниже).
- **Пароли** (ваши сохраняются для быстрого старта), **сохранения состояния**, десять переключателей **читов** и
  переключатель скорости игры.
- **Режим голоса** (Voice mode): как часто диктору можно повторяться.
- Мастер настройки при первом запуске. Каждая страница меню работает и одной мышью.

## Установка

**Windows:** скачайте со страницы [последнего релиза](https://github.com/DarthNuts/ZeroTyperance/releases/latest)
один из двух вариантов.

- **`ZeroTyperance-0.3.0-setup.exe`** — установщик:
  - права администратора не нужны;
  - ставит игру в `%LOCALAPPDATA%\Programs\ZeroTyperance`;
  - добавляет пункт в меню «Пуск» (и ярлык на рабочем столе, если отметить);
  - добавляет запись в «Параметры → Приложения» для удаления.

  Запуск более нового установщика позже обновляет игру.
- **`ZeroTyperance-0.3.0-windows-x64.zip`** — переносная версия: распакуйте куда угодно (подойдёт и флешка) и
  запустите `ZeroTyperance.exe` в этой папке.

Оба варианта содержат Node.js 24.22.2 и скачивают образ ROM (см. выше) при установке или первом запуске. Файлы
не подписаны, поэтому Windows SmartScreen может сказать «Система Windows защитила ваш компьютер»: нажмите
**Подробнее**, затем **Выполнить в любом случае**.

Windows, через PowerShell (устанавливает команду `zerotyperance`):

```powershell
irm https://github.com/DarthNuts/ZeroTyperance/releases/latest/download/install.ps1 | iex
```

Linux, macOS:

```sh
curl -fsSL https://github.com/DarthNuts/ZeroTyperance/releases/latest/download/install.sh | bash
```

Однострочные установщики кладут в одну папку три вещи: игру, её небольшой локальный сервер и отдельную копию Node.js
24.22.2 (скачивается с nodejs.org и сверяется с закреплённым SHA-256). Ещё они добавляют команду
`zerotyperance`:

| | папка | команда |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\ZeroTyperance` | `zerotyperance` (PATH пользователя) и меню «Пуск» |
| Linux, macOS | `~/.local/share/zerotyperance` | `~/.local/bin/zerotyperance` |

Права администратора не нужны. Повторный запуск установщика обновляет игру.

## Игра

**Приложение для Windows** (установщик или переносной zip): запустите **ZeroTyperance** из меню «Пуск» или
`ZeroTyperance.exe`.
- Игра открывается в отдельном окне: режим приложения Microsoft Edge, а без Edge — Chrome или браузер по умолчанию.
- Пока работает игровой сервер, программа сидит в области уведомлений рядом с часами.
- Щелчок по значку снова открывает окно; правый щелчок и **Quit** — останавливает программу.

**Команда** (однострочные установщики):

```sh
zerotyperance
```

Она запускает игру на `http://localhost:8802/` и открывает браузер (Chrome, Edge или Firefox).
- При первом запуске страница проверяет образ ROM и один раз извлекает ресурсы (несколько минут).
- Без скачанного образа страница попросит выбрать файл.
- Чтобы остановить программу, закройте её окно или нажмите Ctrl+C.
- Параметры: `--port N`, `--no-open`.

### Где хранятся настройки

Игра хранит в собственном хранилище браузера для своего адреса `http://localhost:8802` (local storage и IndexedDB):
- настройки (управление, видео, звук, читы);
- сохранённые пароли;
- сохранения состояния;
- извлечённые ресурсы.

Это хранилище — часть профиля браузера в вашей учётной записи, оно никогда не лежит в папке игры:

- Windows (приложение открывает Microsoft Edge): `%LOCALAPPDATA%\Microsoft\Edge\User Data`; Chrome:
  `%LOCALAPPDATA%\Google\Chrome\User Data`.
- Linux: `~/.config/google-chrome`, `~/.config/chromium`, `~/.config/microsoft-edge` или `~/.mozilla/firefox`.

В папке игры лежат только программа, образ ROM (`rom`) и, у приложения для Windows, его журнал `ZeroTyperance.log`.
Другой порт или другой браузер начинают с чистыми настройками, поэтому оставляйте между запусками тот же порт.
Очистка данных сайта `http://localhost:8802` в браузере сбрасывает всё (см. «Удаление»).

## Кооператив

- **Откуда угодно (по умолчанию):** оба игрока запускают ZeroTyperance.
  - Первый выбирает **Co-op → Host a game** и называет комнату (по умолчанию «Zero Tolerance»; имя компьютера, когда комната открывается на собственной
    программе хоста). В строке
    **Password** он выбирает, откуда начнётся игра: New game или пароль из списка (или введённый), как на странице
    Password. Код комнаты он сообщает второму.
  - Второй выбирает **Co-op → Join a game** и вводит этот код. Игроки за одним роутером могут также выбрать комнату
    по имени из списка, а потом ввести код.
  - Игра идёт через кооп-сервер ZeroTyperance по адресу `85.235.151.36` (TCP и UDP, порт 47810), проброс портов не
    нужен.
  - Если хост не может достучаться до этого сервера, комната открывается на собственной программе хоста. Игроку из
    другой сети тогда нужен адрес хоста, как описано ниже.
- **Одна сеть:** всё работает так же. Без кооп-сервера страница Join всё равно показывает открытые игры вашей
  локальной сети. Можно и открыть адрес хоста, например `http://192.168.1.20:8802/`, и ввести код комнаты. В Windows
  разрешите Node.js доступ к частным сетям, когда система спросит.
- **Интернет без кооп-сервера:** оба игрока вводят адрес программы хоста в **Co-op → Server** (введённый адрес
  используется один, без кооп-сервера).
  - Хост вводит `localhost:8802`, второй игрок — `АДРЕС-ХОСТА:8802`.
  - Хост пробрасывает на свой компьютер TCP-порт 8802.
  - Второй игрок открывает `http://АДРЕС-ХОСТА:8802/`, вводит там адрес и входит по коду комнаты.
  - В первый раз эта страница попросит у второго игрока образ ROM. Программа хоста отдаёт свою копию только своему
    компьютеру и своей локальной сети (установленный ZeroTyperance хранит её в своей папке, `rom/Zerotole.bin`).
- Обоим игрокам нужны один и тот же образ ROM и одна и та же версия ZeroTyperance.

## Сеть и приватность

- **Порт 8802.** Программа слушает его на всех сетевых интерфейсах, чтобы второй игрок мог подключиться.
  - У кооп-сервиса нет паролей и шифрования (обычные `http://` и `ws://`). Любой, кто достучится до порта, может
    открыть страницу и войти в открытую игру по её коду.
  - В локальной сети страница Join показывает список открытых игр. Игрок из интернета списка не получает и должен
    ввести код.
  - Образ ROM отдаётся только этому компьютеру и вашей локальной сети.
  - Оба правила смотрят на адрес, с которого пришёл запрос. За обратным прокси или туннелем на этом компьютере (nginx,
    ngrok, `ssh -R`, ...) каждый запрос выглядит локальным, и тогда список и образ ROM получает любой, кого пускает
    туннель. Пробрасывайте сам порт.
- Программа также отвечает на STUN-запросы на UDP-порту 8802: она сообщает партнёру по кооперативу адрес и порт,
  которые видит. Это нужно для прямого соединения двух браузеров.
- Программа слушает и IPv6. На компьютере с публичным IPv6-адресом и без файрвола порт 8802 доступен из интернета без
  всякого проброса портов.
- Пока программа работает, она раз в секунду объявляет свои открытые игры в локальной сети (UDP-порт 47811). В
  объявлении есть имя вашего компьютера и имена комнат, коды — никогда.
- **Кооп-сервер** по адресу `85.235.151.36` (TCP и UDP, порт 47810) держит автор ZeroTyperance.
  - Страница подключается к нему, только когда игрок выбирает Host a game или Join a game при пустой строке Server.
  - Сервер видит ваш IP-адрес и имя и код комнаты. Ещё он видит сетевые адреса, которые браузер предлагает для прямого
    соединения со вторым игроком; среди них может быть ваш адрес в локальной сети.
  - Сервер передаёт двум страницам данные для установки соединения друг друга. Когда браузеры не могут соединиться
    напрямую, через него идут игровые сообщения.
  - Его соединения не шифруются (`ws://`).
  - Кооп-программа на этом сервере ничего не хранит. Её журнал записывает только время, событие, код комнаты и
    сетевую часть вашего адреса: первые три числа адреса IPv4 или первые 48 бит адреса IPv6.
  - Введите другой сервер в **Co-op → Server**, чтобы пользоваться только им.
- **Без телеметрии.** Кроме этого сервера, страница и программа ни с чем не связываются.
  - Однострочные установщики обращаются только к GitHub (этот релиз), nodejs.org (Node.js) и technopop.net или
    web.archive.org (образ ROM).
  - Установщик и переносная версия для Windows уже содержат Node.js и обращаются только к technopop.net или
    web.archive.org (образ ROM).

## Удаление

Приложение для Windows: установленное — через «Параметры → Приложения → ZeroTyperance → Удалить»; переносное — удалите
его папку.

Windows, установка через PowerShell:

```powershell
$env:ZT_UNINSTALL=1; irm https://github.com/DarthNuts/ZeroTyperance/releases/latest/download/install.ps1 | iex
```

Linux, macOS:

```sh
curl -fsSL https://github.com/DarthNuts/ZeroTyperance/releases/latest/download/install.sh | bash -s -- --uninstall
```

Извлечённые ресурсы остаются в браузере, пока вы не очистите данные сайта `http://localhost:8802`.

## Исходники

- **`source/`** — TypeScript страницы (ровно те модули, что входят в релиз, без комментариев), её пакет данных со
  значениями правил и её сборка. `cd source && npm install && npm run build` создаёт `source/site/`. Он побайтно
  совпадает с папкой `app/` архива релиза, кроме `version.json`, который добавляет релиз.
- **`audio/`** — исходник аудиорендерера на C.
- **`launcher/`** — программа, которую установщик ставит рядом со страницей:
  - `launch.mjs` — команда `zerotyperance`;
  - `server/server.mjs` — локальный веб- и кооп-сервер;
  - `unzip1.mjs` — распаковывает zip с образом ROM.
- **`windows/`** — исходники приложения для Windows:
  - `launcher.c` и `launcher.rc` — `ZeroTyperance.exe`, собирается MinGW-w64;
  - `setup.nsi` — установщик, NSIS 3;
  - `fetch_rom.mjs` — загрузка образа ROM;
  - `make_icon.py` — рисует `zt.ico`.
